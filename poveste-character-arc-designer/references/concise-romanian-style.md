# Concise Romanian Style

## General rule

Use the fewest words needed to communicate the idea clearly and naturally.

Do not confuse completeness with length.

## Prefer

- Natural Romanian
- Short and medium-length sentences
- Active voice
- Concrete nouns
- Specific verbs
- Clear dialogue
- One strong image instead of several similar images
- Action instead of abstract explanation
- Selective sensory details
- Intentional repetition
- Short paragraphs
- Direct headings

## Avoid

- Long introductions
- Generic praise
- Repeating the user's input
- Repeating the same decision in several formats
- Excessive adjectives and adverbs
- Long psychological explanations
- Unnecessary backstory
- Several alternatives when one recommendation is enough
- Filler events
- Formal or translated-sounding Romanian
- Long chains of subordinate clauses
- Dialogue used only for exposition
- Explaining emotions that can be shown through action

## Planning style

Use concise fields:

```yaml
wants: să ajungă acasă
problem: poteca dispare
fear: să nu pară nepricepută
tries: caută singură drumul
learns: ajutorul poate fi un act de curaj
choice: își întreabă prietenul
change: acceptă sprijinul
```
