# Poveste de Seară Story Skills

Skills for planning Romanian bedtime stories for Poveste de Seară.

## Skills

- `poveste-story-architect`
- `poveste-character-arc-designer`
- `poveste-story-inbetweener`
- `poveste-split-story`

## Workflow

1. Story Architect
2. Character Arc Designer
3. Story Inbetweener
4. Split Story, when needed
5. Mat Pocock's handoff skill
6. Writing Beats skill
7. Romanian story draft
8. Poveste de Seară validation

The creative skills must prepare a package for Mat Pocock's handoff skill. They
must not directly invoke or replace the Writing Beats skill.

## Installation

```bash
npx skills add mateevskici/story-writing-skills
```

Install one skill:

```bash
npx skills add mateevskici/story-writing-skills \
  --skill poveste-story-architect
```

List available skills:

```bash
npx skills add mateevskici/story-writing-skills --list
```

## Principles

- One central idea
- One main character
- Gentle but meaningful conflict
- Protagonist agency
- Natural, concise Romanian
- Clear cause and effect
- Necessary supporting characters only
- Visible emotional change
- Calm, emotionally safe endings
- Challenge ideas that conflict with the guidelines
